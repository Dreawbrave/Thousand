# Набор реакций

Все стикеры — прозрачные PNG размером 512×512. Клиент сможет загружать список из `manifest.json`.

Чтобы добавить пользовательский стикер:

1. подготовьте прозрачный PNG 512×512 без текста и внешних ссылок;
2. положите файл в эту папку с коротким латинским именем;
3. добавьте объект `{ "id", "label", "src" }` в `manifest.json`;
4. перед публикацией пользовательских файлов проверяйте MIME-тип, размер и фактическое содержимое изображения на сервере.

`dice-reactions-sheet.png` — исходный прозрачный лист базовой серии. Отдельные файлы созданы скриптом `scripts/split_sticker_sheet.py`.

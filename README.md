# Косарь — онлайн-«Тысяча» на костях

Полноценная live-игра для компании: React + Vite + TypeScript на клиенте, FastAPI + WebSocket на сервере. Сервер сам бросает кости, считает максимальную комбинацию и синхронизирует одно состояние для всех игроков.

## Что уже работает

- комнаты по пятизначному коду, автоматическое переподключение и восстановление из Redis;
- розыгрыш очередности, последовательные ходы и реванш;
- 1/5, тройки/четвёрки/пятёрки, оба стрита и «горячие кости»;
- обязательное открытие с 50, ямы 200–300 и 600–700;
- болты (каждый третий = −50), самосвал на 555, победа от 1000;
- адаптивный интерфейс для телефона и компьютера;
- единый Docker-образ: фронтенд и API работают на одном домене.

## Запуск локально

Нужны Node.js 20+ и Python 3.11+. Redis для локальной разработки необязателен.

```bash
npm install
npm --prefix frontend install
python -m pip install -r backend/requirements-dev.txt
npm run dev
```

Откройте `http://localhost:5173`. Vite автоматически проксирует HTTP и WebSocket на FastAPI (`localhost:8000`). Для проверки:

```bash
npm run build
npm test
```

Без переменных окружения сервер использует оперативную память. Чтобы локально проверить сохранение, скопируйте `.env.example` в `.env` и вставьте данные своей базы Upstash.

## Бесплатный деплой на Render

В репозитории уже есть `Dockerfile` и `render.yaml`, поэтому отдельные хостинги для клиента и сервера не нужны.

1. Создайте репозиторий на GitHub и отправьте туда проект.
2. В Render нажмите **New → Blueprint**.
3. Подключите репозиторий и подтвердите создание сервиса из `render.yaml`.
4. Render попросит значения `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`. Получите их на вкладке **Details** созданной базы в [Upstash Console](https://console.upstash.com/).
5. После сборки откройте выданный адрес `https://…onrender.com` — HTTPS и `wss://` включатся автоматически.

Также можно выбрать **New → Web Service**, подключить репозиторий, указать runtime **Docker** и тариф **Free**, а затем вручную добавить две секретные переменные Upstash.

## Бесплатный Redis через Upstash

1. Зарегистрируйтесь в [Upstash](https://console.upstash.com/) и нажмите **Create Database**.
2. Выберите план **Free** и ближайший к Render регион.
3. На вкладке **Details** скопируйте REST URL и REST Token.
4. Добавьте их в Render: **Environment → Add Environment Variable**.

Проект использует HTTP-клиент Upstash: постоянное TCP-соединение не требуется. Комната записывается только после создания, подключения игрока или игрового действия; WebSocket-heartbeat Redis не расходует. Состояние одной комнаты занимает считаные килобайты и автоматически удаляется через 7 дней бездействия. Бесплатный тариф Upstash сейчас предоставляет 256 МБ и до 10 000 команд в день — для небольших дружеских партий этого с большим запасом достаточно.

### Ограничение бесплатного режима

Активные комнаты кэшируются в памяти, а их надёжная копия лежит в Upstash Redis. После сна или перезапуска Render сервер загружает комнату обратно при следующем HTTP/WebSocket-подключении. Если Upstash-переменные не заданы или сервис временно недоступен, игра продолжает работать в режиме памяти, но новые изменения в этот момент не будут сохранены.

[Бесплатный Render](https://render.com/docs/free) засыпает после 15 минут без входящих HTTP-запросов или WebSocket-сообщений и может просыпаться около минуты; клиент отправляет heartbeat и автоматически переподключается. Подробнее: [WebSockets on Render](https://render.com/docs/websocket), [Upstash Python SDK](https://upstash.com/docs/redis/sdks/py/gettingstarted), [Upstash Redis pricing](https://upstash.com/pricing/redis).

## Структура

```text
frontend/           React-приложение
backend/app/game.py правила и состояние партии
backend/app/main.py REST, WebSocket и раздача production-фронтенда
backend/app/storage.py сохранение и восстановление комнат через Upstash
backend/tests/      тесты игровых правил
Dockerfile          production-сборка
render.yaml         бесплатный Render Blueprint
```
